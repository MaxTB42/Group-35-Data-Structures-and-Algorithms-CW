# ECM1414 - Data Structures and Algorithms CW - Group 35

## Description
This projects generates a list of activities that a university society could do to maximise the enjoyment of the 
participants whilst keeping to a cost budget. It uses a list of files with increasing number of activities. It does this
in two different ways, a brute force approach and a dynamically programmed approach, both are timed and outputted.
